Week strip

Seven-day pill row used as a date picker at the top of the Calendar sub-tab. Every day is equally readable and tappable — past, present, future, with or without events. Small category-coloured dots below each date number indicate which categories of events exist on that day.

Rules

  1. Every day pill renders with the same background rgba(255,255,255,0.10), same text colour, same border. No muted/disabled treatment for days without events — every day is tappable.
  2. Each pill always reserves a 5px-tall indicator row with margin-top: 3px, even on empty days. This keeps card heights consistent across the row.
  3. On days with events, render up to 3 dots (5×5px, fully round, 3px gap between dots). Each dot represents one unique category present that day.
  4. Dot order is fixed: work → personal → health. Never re-order based on event count or alphabetisation.
  5. If a day has more than 3 unique categories (impossible today, but defensive), cap at 3.
  6. On the active/today pill (yellow background), dot colours switch to the -on-accent variants for legibility. The personal dot becomes white because yellow-on-yellow would vanish.
  7. Events with no category field render no dot. They count toward "the day has events" only if accompanied by at least one categorised event. Treat uncategorised as benign, not as an error.

Tokens

Defined in app/globals.css under :root. Used directly via var(--ff-cat-*) in inline style on the dot element — not as Tailwind-generated bg-* classes — to avoid Tailwind v4 theme-registration issues.

Data shape

Event item
{ time: string; title: string; category?: 'work' | 'personal' | 'health' } — category is optional.
Day item
{ dow: string; num: number; isToday?: boolean; items: EventItem[] }
Categories derivation
Compute at render time: const cats = unique(day.items.map(i => i.category).filter(Boolean)), then sort by CATEGORY_ORDER = ['work','personal','health'].
Shared types
lib/categories.ts exports EventCategory and CATEGORY_ORDER. Reuse on the Today screen and on To-do/Countdown rows when those adopt the system.
