Type rationale

Rationale moved to CHANGELOG.md (see token tuning entries on 2026-05-07).

Sizing

Buttons are content-width by default — width:auto, min-width:120px, max-width:280px. Position and alignment are controlled by the parent layout (e.g., centered within a card, anchored to a notification action stack), not by the button itself. There is no full-width CTA pattern in Focus Forest.

Disabled state

Disabled state is intentionally neutral. Both Primary and Secondary disabled buttons render identically (--color-grey-light background, low-opacity black text), since disabled is an absence of action rather than a brand-flavored state. Ghost retains its low-opacity white treatment for use on dark surfaces.
