Type scale rules One token per role. Each token defines a single weight, size, and use case — don't apply Niramit Light at 38px to body text, or Source Sans Semi-Bold at 16px to a heading. The system intentionally constrains weight per size to maintain visual rhythm.
Font family signals hierarchy, not just size. A heading and a body paragraph can both be 16px — the heading uses Niramit Semi-Bold (display family), the body uses Source Sans Regular (body family). Family + weight differentiate them.
iOS system tokens are off-limits for app UI. Group 03 tokens render only on OS-controlled surfaces (lock screen, system notifications). Inside the Focus Forest app, only Groups 01 and 02 apply.
Line-height & letter-spacing. Defaults: line-height 1.4 for body tokens, 1.2 for display/heading tokens, 1.0 for buttons. Letter-spacing 0 for all tokens unless noted.
Font-weight scale. Token defaults use 300 (Display), 400 (Body Regular), 500 (Medium — h1-h3, button, overline, list-label), and 600 (h4). Weight 700 (Bold) is reserved for the brand logo glyph only (see components-app-header.html) and is not a general token.
