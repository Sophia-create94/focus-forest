Previous
Was previously a yellow-tinted nested glass card. Restructured 2026-05-19 to avoid double-blur and to keep ONE glass recipe across the product.
One glass recipe, end to end. Previously there were three distinct glass treatments (Card primitive, Section card, Nested countdown) that diverged in radius, blur, border opacity, and gradient strength. Collapsed to one canonical recipe on 2026-05-19 for visual consistency. Do not nest glass surfaces — backdrop-filter inside another blurred element double-blurs and looks muddy. For sub-items inside a section card, render them as bare rows with optional accent bars / urgency styling. The Card primitive accepts asChild so semantic tags (<article>, <section>) can be preserved while still emitting the canonical glass surface.
Typography contract for glass cards (post-2026-05-21 pass, mirrored on /components): every card title uses --text-h4 (16 / Display 600) except the Home hero which uses --text-h3 (20 / Display 500) for the level-up callout; every sub-header / supporting line uses --text-body (14 / Body 400) at white/60-70; interactive list items (to-dos, settings rows, agenda items) use --text-list-label (16 / Body 500); tiny uppercase overlines and pills (Now, UP NEXT, AM/PM, day-circle Tue, WeekStrip initials) use --text-overline (11 / Body 500 / .02em).
