Canonical scale: xs 4 · sm 8 · md 14 · lg 18 · pill 9999. The Card primitive's glass surface uses md (14px) as of the 2026-05-19 glass-surface consolidation.

Component-specific radii: checkbox 3px (used by Checkbox primitive only) · input 10px (used by Input primitive only). These exist alongside the canonical scale to match shipped component values.

Prefer pill (9999px) for all rounded UI elements — circles, pills, dots, avatars, FABs, badges. The brand token produces a circle on symmetric (w=h) elements and a pill on asymmetric ones; it's always correct. full (50%) renders as an ellipse on non-square dimensions and is retained only for historical compatibility.
